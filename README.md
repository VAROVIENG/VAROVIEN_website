# VA ROVIENG CO.,LTD Website

A modern, responsive website for VA ROVIENG CO.,LTD - A newly established company beginning its journey in copper and gold exploration.

## 🌐 Live Website

Visit the website: [VA ROVIENG CO.,LTD](https://varovieng.github.io/VAROVIENG-website/)

## 📋 Project Overview

VA ROVIENG CO.,LTD is a newly established company focused on copper and gold exploration. This website showcases:

- **Company Background**: Information about the company's beginning and mission
- **Areas of Interest**: Details on copper and gold exploration
- **Project Activities**: Photo galleries of drilling activities, machinery, and raw materials
- **Our Approach**: Information about the company's exploration methodology
- **Presentations**: Additional resources and presentations

## ✨ Features

- **Responsive Design**: Fully responsive website works on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean and professional design with smooth interactions
- **Photo Galleries**: Interactive carousels for viewing drilling activities, machinery, and materials
- **Progressive Web App**: Service worker support for offline functionality
- **Accessibility**: WCAG 2.1 AA compliant with proper semantic HTML
- **Performance Optimized**: Fast loading with optimized images and efficient code
- **Custom Scrollbar**: Interactive custom scrollbar for better navigation
- **Modal Photo Viewer**: Full-screen photo viewing capability

## 🛠 Technology Stack

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **JavaScript (Vanilla)**: Interactive features without external frameworks
- **Bootstrap 5.3.9**: Responsive grid and utility classes
- **Google Fonts**: Typography with DM Sans, DM Mono, and Playfair Display
- **Service Worker**: PWA support for offline browsing

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (for development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Austin2709/va-rovieng-website.git
cd va-rovieng-website
```

2. Start a local development server:
```bash
# Using Python 3
python -m http.server 8000

# Or using Node.js (http-server)
npx http-server

# Or using PHP
php -S localhost:8000
```

3. Open your browser and navigate to `http://localhost:8000`

## 🎨 Customization

### Colors
Main colors are defined in `styles.css`. Key color variables:
- Gold/Brand: `#b39c1e`
- Text: `#1a1a1a`
- Backgrounds: `#ffffff`, `#f5f5f5`

### Fonts
- Headings: Playfair Display
- Body: DM Sans
- Code/Numbers: DM Mono

### Images
Replace images in the `images/` directory while maintaining the same filenames.
